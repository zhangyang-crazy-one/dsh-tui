# @deepseek-ai/dsh-tui-render

English | [中文](README.zh.md)

## Summary

`@deepseek-ai/dsh-tui-render` lets the terminal runtime project bounded session history, panels, Markdown, tool cards, and input through Ink. Callers supply a controller snapshot and receive terminal rendering and input actions without giving the library ownership of agents or persistence. The package registers no Cordis service and issues no model request.

<a id="use-this-package"></a>
## Use this package

The `dsh-tui` runtime imports this library when it already owns terminal lifecycle and a `TuiController`. Use [`mountTuiRender`](src/index.ts) to mount the Ink tree and dispose the returned handle during runtime teardown; use the pure projection and layout exports for owner tests and alternate terminal hosts.

The default [Soft Slate theme](../../../.agents/notes/implemented/feature/2026-09-02-tui-soft-slate-visual-hierarchy.md) separates the frame, user messages, tool cards, code, and input/status band while preserving truecolor, 256-color, 16-color, and `NO_COLOR` fallbacks. The terminal emulator still owns the font and line height.

### Contract

- `TuiLoop` observes a `TuiController` snapshot and dispatches input actions without accessing agent or persistence services. The top-bar title is `controller.getTitle()`: a folded `session/title` except a `fallback` title that coexists with a human user message (that echo is a directory-row label only). Before a provider or rename title exists the loop shows the compact mount title `DeepSeek · deepseek-tui`; the large generated FishLogo remains in the empty home rather than the top bar. `SessionPane` appends a shortest-unique session-id hint only when several rows have the same folded title, keeping distinct sessions identifiable without a dedicated identity row. While `getApprovalPane().open` is true the composer slot is `ApprovalPane` (inline permission question with `[Y] 允许 · [n] 拒绝 · [a] 本会话总是` and optional details); while `getAskUserPane().open` is true it is `AskUserPane` (numbered labels, footnote `↑↓/jk 移动 · 1-9 选择 · Enter 作答 · Esc 取消提问`). StreamView stays in `children` in both cases; `g s` (composer buffer exactly `g`) / Ctrl+K / Ctrl+T / `/help` / empty `/permission` / empty `/settings` do not open browse panels. While `getSettingsPane().open` is true the conversation column is `SettingsPane` (`设置`, or `首次设置` when `onboarding` is set; `namespace · field` rows such as `llm-deepseek · baseURL`); browse leaves the composer empty (`↑↓/jk 选择 · Enter 编辑 · e 导出 · r 重载 · Esc 关闭`) and edit uses `InputBar`. `getSubmitOnEnter()` is false when Enter should insert a newline. `InputBar` segments ordinary text, slash commands, `@` mentions, and durable `[图片 #N]` placeholders into exact, lossless slices; styling changes only their presentation and the `none` color tier preserves the same literal text. `CommandMenu` paints under it as a two-column list (`/{name}` left, description right), both sides escaped; command and mention menus share Up/Down and j/k selection, and the selected row uses an accent `›` and an `fg` name. Enter on a non-empty `/` query executes the highlighted name-prefix match and keeps trailing arguments; empty `/` plus Enter does not fire a directory item.
- `createProjector()` treats only `user/message` events with `source.kind === 'user'` as human transcript rows. Agent instructions, plugin context, skill catalogs, and future non-user sources remain durable and model-visible without appearing as user-authored terminal messages.
- `SessionPane` renders supplied session rows, selection and delete confirmation state; persistence reads and mutations remain runtime-owned.
- **AppShell / StreamView layout** — the top bar sits above a thin full-width `─` separator; thick `═ ║` chrome is not used. `layoutTitleBar` fits the title and badge into the window width (badge truncates first when the title still fits; a one-column `…` marks a cut; wide glyphs stay whole). `conversationWidth` uses the complete width below 40 columns and otherwise leaves two safe columns on each side, while the generated official FishLogo, `DeepSeek` wordmark, and greeting remain independently centered. The transcript, reasoning, Markdown tables, tool cards, and related HUDs use this near-full-width reading area so structured output is not forced through an 88-column cap. When Todo, Jobs, Workflow, composer, or queue HUD rows are present, their shared conversation container fills the fixed AppShell content slot and StreamView receives all remaining rows; a one-line HUD cannot collapse the transcript to zero height. A Markdown table keeps its natural width when it fits and shrinks or wraps columns only when it exceeds the row budget. Constrained tables compare wrap-count gains, retain compact status columns and readable identifier minima, and use balanced widths unless unequal widths reduce record height. Multi-line records receive thin separators. Cell wrapping keeps fitting words whole and uses terminal display widths for oversized identifiers and CJK text. Assistant Markdown reserves matching left and right body insets before wrapping, keeping tables symmetric and preventing Ink truncation from removing text. `InputBar` is a separate full-width `inputBg` workspace with an accent left rail, title/hint row, and draft rows; the full-width status area follows it with one quiet row by default, with active goal progress taking priority over generic hints. Explicit status details use up to three height-aware rows; the input chip is the sole default model label. Resize reflows both areas, and low height removes lower-priority status rows and selects a smaller brand tier before it can displace the composer. StreamView clips one fixed content slot and owns the only transcript scroll coordinate in wrapped physical terminal rows. ↑/k and ↓/j move one physical row, PageUp/PageDown move one viewport minus one row, Home reaches the oldest row, and End or an empty-composer `G` atomically reattaches to the latest row. Ordinary downward navigation and a rail jump to the live edge also restore follow mode and clear unseen rows. A detached viewport retains `{blockId,rowWithinBlock,viewportRow}` while streaming, freeze, tool completion, compaction, cache reconstruction, or resize changes surrounding layout. While detached, a fixed bottom-right notice reads `↓ 底部 · End/G` and adds `最新消息 · {n}` when physical rows arrive; the overflow-only rail is painted after each Ink frame with absolute terminal coordinates in the rightmost control column, so emoji-width differences cannot move one track row. The `scrollbar` prop disables both rail paint and mouse hit testing without changing reading width or the detached notice. Its visible cells and mouse region share the same geometry, and primary-button click or drag maps the rail to the oldest-through-live range before text selection can start. The complete history remains canonical in block/source descriptors while `TranscriptRenderStore` mounts only the exact physical rows intersecting configured overscan; settled row arrays keep stable identities, current viewport/active/anchor blocks are pinned, and configured row/byte LRU limits evict only reconstructable derived rows. User and assistant rows left-align in the reading area; a full-width `messageBg` fill distinguishes user rows while assistant prose stays on the frame, and `>` / `●` preserve speaker identity without opposite edges. An assistant turn paints chronological reasoning, prose, and tool cards. Closed tool stacks retain at most three representative cards, put older calls in one `工具记录` card, and expose bounded per-card previews with Ctrl+E; nonzero terminal exits and signals remain visible as failures. Adjacent cards have no blank transcript row. Reasoning is hidden by default without a fold marker. Ctrl+O displays its complete dim body in the shared transcript during streaming and after settlement; final Markdown remains strongest and TurnTail/completion metadata stays dim. Paragraph line breaks and complete fenced-code bodies remain navigable without a local 500-line cap. Parsed top-level Markdown blocks retain one physical blank row, so headings, paragraphs, lists, tables, and code blocks remain visually distinct. StreamView never paints a cursor glyph inside assistant prose; the hardware caret belongs to the composer. The physical-row projection keeps one blank row between reasoning, tool stacks, and prose. Pending and final-visible reasoning durations advance every tenth of a second between model events; the timer stops when prose or a tool becomes the last visible part. When the provider supplies no reasoning text, the TUI shows the dynamic progress label without synthesizing hidden chain-of-thought. Message blocks retain two blank rows between them and one inside the active turn. In colored tiers, `frame-fill` keeps the `bg` token active for each complete Ink string write and reapplies it after SGR resets. The input and status areas use Ink full-width Box geometry, while `paintBackgroundRow` restores the owning background token around reset-terminated content runs and emits the remaining measured background cells; every layout cell is therefore painted without depending on Text-embedded line erasure, terminal BCE, or Ink retaining Box-tail spaces. Visible-screen and line erases inherit the page background; scrollback erasure temporarily restores the terminal default, and the write ends with the default restored. The `none` tier adds no background ANSI.
- `mountTuiRender()` owns the Ink alternate-screen lifecycle and returns the matching unmount disposer; before the first render it installs the color tier detected from the environment (`installTheme(env)`, default `process.env`, injectable for tests), so every `styled()` call in the tree maps through the detected tier (truecolor → 256 → 16 → none). The same snapshot installs OSC 8 (`installHyperlinks(env)`). The host supplies a validated `renderPolicy` for transcript overscan, stream pacing, latest-target scrolling, and row/byte cache limits; `frameMetrics` records projection, queue, scroll, cache, and stdout-drain measurements. When given a `frameProbe` it wraps the tree in a `FrameProbe` so every React commit records its render cost.
- **Mouse and OSC 8** — on a TTY pair `mountTuiRender` enables SGR mouse (`1000`/`1002`/`1006`), strips reports from Ink's stdin, and disables tracking on unmount even when `render` throws. Unknown terminals and tmux/screen that do not advertise hyperlink forwarding keep plain text, with a dim `(href)` when the label differs from the href (`mailto:` compared without the scheme). Markdown links and collapsed tool-card summaries wrap already-styled text in OSC 8 after `escapeContent`/`styled`; only `http(s):`/`mailto:`/`file:` hrefs wrap or open. Product frames publish one shared `VisibleFrameSnapshot` whose physical rows, style spans, hrefs, rail geometry, and source coordinates update `ScreenAtlas` directly; the ANSI/OSC byte parser remains only as the fallback for output without product-owned geometry. Wheel reports in one stdin chunk become one signed request before React input handling, and each report contributes the validated `scroll.wheelRows` physical rows (default 3); settings edit/onboarding still ignore wheel input. A primary-button press in the published rail cells owns click and drag positioning until release and never copies transcript text. Outside the rail, primary-button motion immediately restores the prior overlay and repaints only occupied non-rail cells in the current reading-order range. Release copies through OSC 52 (capped at 100_000 characters) plus a host clipboard helper, then immediately restores the published row styles. The rail cell and its left wide-glyph guard enter neither the overlay nor copied text; rail paint clears both cells when the rail appears, disappears, or moves after resize. A release at a different cell completes that drag even when the terminal omits intermediate motion reports; a same-cell click opens the href under that cell through the host opener. Ctrl+Y is independent of mouse selection and copies the latest non-empty assistant message or its final closed fenced-code body.
- **Generated brand and theme styling** — `scripts/gen-tui-brand.ts` reads the exact `viewBox`, path data, and `currentColor` fill from the repository-owned `FishLogo.tsx` source without importing client runtime code. Deterministic nonzero-fill rasterization preserves the viewBox ratio within 2% on a 44×32 logical bitmap and packs it into the 44×16 A half-block tier; generation rejects stretched dimensions before emitting an artifact. B full-block and C ASCII derive from that same bitmap, followed by the plain `DeepSeek` wordmark. Four A-tier reveal frames keep every contour cell byte-identical and vary only exterior particles. `verify-tui-brand`, included in `doc-sync`, rejects any stale generated artifact. The generic whale emoji is not a brand or fallback tier. `styled(escapeContent(text), token)` is the single styling path: content is escaped before styling, and each token (`accent`/`success`/`error`/`fgDim`/…, the closed `THEME_LEVELS` set) maps through the installed tier. Truecolor `accent` is DeepSeek logo blue `#4D6BFE`; `accentText` is the lighter `#7589FF` used for small interactive text. The 16-color tier keeps secondary text distinct from the input background; at `none`, text renders unstyled. `formatAdaptiveInfoFooterRows` paints the available subset of up to three semantic rows from controller-provided workspace/status, provider/model, optional effort, context pressure, complete input/output token totals, cache-hit percentage, operation hints, and a durable retry countdown; `formatAdaptiveInfoFooter` exposes the same selection as plain text. Context uses a ten-cell bar plus percentage when it fits and degrades to percentage or numeric occupancy as a complete segment. Input is uncached input plus cache-read and cache-write tokens; the percentage divides cache-read by that same total, disappears without prompt input, and never substitutes an opaque raw cache-token total. The formatter drops complete low-priority rows and segments as geometry narrows, escapes provider and failure text, and has no cost field because the runtime exposes no authoritative billing projection. The feedback row (`feedbackLine` — `✓` copy renders success, `✗` and other failure copy renders error), selected/list/timeline-current markers (`accent` or `accentText` by size), the generated idle contour and wordmark, the full-width input workspace, and panel footers (fgDim) complete the styled semantic matrix. Markdown renders through the same path: code spans map to tier tokens over a per-line `codeBg` strip (no hard-coded truecolor); headings and GFM table headers use readable `accentText`, while strong text, emphasis, inline code, and links use distinct gold, lavender, mint, and cyan tokens. Paragraphs and lists preserve nested styles; `styled` supplies inline code's foreground and background to both normal and direct-scroll painters (links retain the OSC 8 wrap above). Overlay pane titles stay bold fg.
- `escapeContent`, `displayWidth`, `wcwidthSafeSlice`, `padDisplayEnd`, and `wrapDisplayLines` — the render layer owns control-byte escaping, display-width measurement, column padding, and column wrapping (the `string-width` dependency lives here); the host re-exports `escapeContent`, `displayWidth`, and `wcwidthSafeSlice` so host-side imports keep working. Active and settled GFM tables use the same allocator and word-aware cell wrapper, share a display-width maximum per column (`padDisplayEnd`), preserve natural column widths when the complete grid fits, wrap cells inside a box-drawing grid (`┌─┬─┐` / `├─┼─┤` / `└─┴─┘`), and fall back to readable key/value records when aligned columns cannot meet their minimum widths; markdown rows set Ink `wrap="truncate"` so a fitted line cannot wrap a second time and overwrite the row below.
- `composerCursorPosition` / `composerFrameAnchor` / `clampCaretIndex` / `moveCaretByGrapheme` retain grapheme-safe buffer coordinates. `InputBar` publishes an absolute terminal row/column and hides it when a pane owns input. The frame wrapper restores Ink's bottom-origin erasure before its write, then commits the current caret with the transcript and rail. Repeated overlays are idempotent; cursor-only moves still emit CUP. A horizontal draft window keeps the caret and nearby text visible with a `‹` continuation marker, without changing the stored buffer. Ink 7.1.1 exposes no IME composition state; native preedit and physical glyph alignment still require terminal-specific checks.
- `FrameProbe` records React Profiler `actualDuration` for every subtree commit. Each duration channel retains 120 exact recent samples and a fixed-storage full-run histogram with count, mean, p95, p99 and maximum. Histogram quantiles use microsecond buckets with three significant digits; `beginMeasurement()` discards startup/hydration once, while later window resets preserve the full-run distribution. Root and brand render costs exclude Ink diff/commit, stdout drain, and physical display latency. `frameMetrics` separately records drain, scroll, completed-write intervals, input/coalescing counts, queue depth and cache work. The mount consumes React development User Timing entries after observers receive them, without retaining component props for the session lifetime or clearing unrelated measurements.
- **Performance bounds** — each streaming Markdown block advances an append-only complete-line collector, retains stable parsed blocks and physical-row references, and reparses only the ambiguous suffix; reference definitions, visualization directives, render-scope changes, and unprovable locality take an explicit safe full-recompute path. A fence-aware table scanner holds back only the active table from its header, while adaptive layout preserves compact values, shrinks token-heavy and narrative columns, and selects key/value records when required. `TranscriptRenderStore`, projector caches, and syntax-token caches are bounded and reconstructable from canonical source. A shared frame arbiter gives scrolling priority over the bounded presentation queue and publishes each changed physical offset, including the final tick. Overscan limits cached rows, not paint frequency. Reversing input replaces pending motion from the displayed position. A burst retains its selected catch-up pace through the final step. Changed scroll offsets also publish the measured snapshot during layout, without waiting for Ink's separate output throttle. Ink's maximum frame rate follows the faster configured stream/scroll cadence. After Ink's incremental output, `VisibleFrameSnapshot` repaints changed visible lines by terminal coordinate and clears shortened or vacated ranges; unchanged physical-line identities emit no overlay writes. After Ink finishes a frame, a changed geometry or settled-turn key clears only the current transcript region. Transcript rows, rail, and absolute caret are committed before the same synchronized-output end marker. Layout-only rail updates use the same synchronized-output frame as transcript painting. Replacing the transcript with a browse pane releases its snapshot, rail, and pointer region during layout cleanup, before the replacement can be painted. `pnpm run test:tui:perf` owns the strict real-PTY long-Markdown, growing-table, 10,000-row scrolling, resize, and slow-sink targets.
- **Tool inspection** — Ctrl+E reveals bounded previews, not a preformatted full body. `/tools` lists every call; Enter opens its paged source, n/p navigate, d opts into raw metadata, y copies complete text, and e exports it. Failure summaries retain exit codes/signals independently of pipeline success. `ToolRowCache` materializes only requested rows under validated entry/row budgets; presenter results and reasoning wrap indexes are reusable and rebuildable. Compact display revisions reference canonical data without embedding complete answers in every frame identifier. New settings, status and detail labels use the typed zh-CN/en-US dictionary.


### Advanced interaction contract

- Dialogs keep StreamView in the content slot and occupy the input slot; browse overlays replace the content and suppress the composer except during their editing states. Todo, jobs, and workflow HUD rows never capture input. The default status row shows a ten-cell context meter, percentage, cache-hit rate, and running state at 80 columns and above, adding compact absolute usage and operation hints when space permits. Missing authoritative values remain absent. Context and cache summaries share their calculation with explicit details; general hints and absolute counts yield before metric summaries, while errors and retries take priority. Retry copy exists only between matching durable `llm/retry` and `llm/retry-started` records. The default footer has one row; explicit details retain up to three rows. A current goal replaces cwd on a constrained first row instead of disappearing.
- [`ModelPane`](src/model-pane.tsx) renders at most 30 catalog rows and moves that window with the highlighted index, so Up/Down or j/k can reach every model in a longer catalog. Its footer reports the counts hidden above and below the current window; Enter applies the highlighted provider/model pair through the runtime controller.
- [`SessionPane`](src/session-pane.tsx) budgets titles, timestamps, current-session markers and duplicate-title id hints against `columns` and `maxRows`. When the current row is visible and height permits, its exact `会话 ID · {parentId}` appears below it. [`AgentHubPane`](src/agent-hub-pane.tsx) retains `子会话 ID · {childId}`. Both panes receive typed `SessionId` values from their controller; [`session-pane.spec.tsx`](tests/session-pane.spec.tsx) and [`agent-hub-pane.spec.tsx`](tests/agent-hub-pane.spec.tsx) own identity and escaping behavior.
- The [`Mention`](src/mention.tsx) selection in [`loop.tsx`](src/loop.tsx) uses Up/Down or j/k to change the highlighted candidate. Enter inserts that target with exactly one trailing space and does not submit it; Escape dismisses the selection menu. [`composer-tokens.spec.ts`](tests/composer-tokens.spec.ts), [`mention.spec.tsx`](tests/mention.spec.tsx), and [`loop-input.spec.tsx`](tests/loop-input.spec.tsx) own lossless tokenization and the focused key behavior.
- [`StreamView`](src/stream-view.tsx), [`ToolCard`](src/tool-card.tsx), and [`turn-tail.ts`](src/turn-tail.ts) render presenter-tagged cards, bounded closed tool stacks, explicit process failures, `── 已完成 ──`, first-seen produced paths, and exact turn-local input/output/cache statistics. [`visual-conformance.spec.tsx`](tests/visual-conformance.spec.tsx) owns the bounded layout rules; the assembled [`terminal.expected.txt`](../../../apps/cli/tests/snapshots/deepseek-tui-advanced-entry/terminal.expected.txt) owns settled 80x24 and 200x50 ScreenAtlas cells. The rationale and evidence ownership are recorded in the [bounded tool-card stack](../../../.agents/notes/implemented/bug-fix/2026-09-04-tui-bounded-tool-card-stack.md) and [advanced-capability](../../../.agents/notes/implemented/feature/2026-08-18-tui-advanced-capability-entries.md) Agent Notes.

<a id="model-experience"></a>
## Model Experience

### Terminal conversation display

#### What the model sees

The renderer adds no prompt text, tool schema, session event or model request; it only displays the runtime's `ViewModel`.

#### Token effect

The package has zero direct token effect because its output is terminal-only.

#### KV Cache effect

The renderer does not alter request prefixes or issue model requests, so it has no KV-cache effect.

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- **Terminal capability fallback** — color, OSC 8, and syntax highlighting degrade to lower terminal tiers; the renderer does not emulate unavailable terminal features.
- **SGR mouse owns the pointer** — mode `1002` replaces the terminal's native selection; copy is the in-process reverse overlay plus OSC 52.
- **Session directory data** — search, timeline and export data remain runtime-owned so this package can render them without owning storage or lifecycle.
- **Physical text input** — the composer uses grapheme-aware horizontal windows and absolute coordinates, but the emulator still owns font metrics and IME preedit. PTY cell assertions do not prove physical-display smoothness.
- **Evicted rows rebuild before presentation** — cache eviction removes only derived physical rows; revisiting an evicted block synchronously reprojects its canonical source, which can make that navigation slower than a cache hit without changing rail geometry or the anchored reading row.
